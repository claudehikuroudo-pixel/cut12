安静にしていても使う分は基礎代謝で数えているので、安静時の分を含まない数字を入れてください。

計算：（メッツ−1）×体重×時間。メッツ＝改訂版『身体活動のメッツ（METs）表』（国立健康・栄養研究所 2012）。1を引くのは、その時間の安静の分は基礎代謝ですでに数えているため（二重に数えない）。どれも目安です。

からだの設定

身長・年齢・性別・ふだんの動き方から、基礎代謝とふだんの動きの消費カロリーを出します。運動は「今日の痩せるカロリー」の「＋ 運動を記録」で、やった日だけ足します。体重は記録（7日平均）を使います。

cm 歳

ふだんの動き方（身体活動レベル）

運動は別に記録して足すので、ここは運動を除いたふだんの動きで選んでください（運動の分まで入れると二重に数えます）。

計算：基礎代謝＝国立健康・栄養研究所の式、活動レベル＝日本人の食事摂取基準（2020年版）、脂肪1kg＝7,000kcal（厚労省 身体活動・運動ガイド2023）。どれも推定なので、2週間の体重の動きで見直してください。

写真カロリーの設定

写真からカロリーを出すのに、Anthropic社のAI「Claude」を使います。Claude Console（platform.claude.com → Settings → API keys）で作ったAPIキーを貼り付けてください（デテコイで使っているキーと同じものでOK）。料金はClaudeの月額プランとは別で、使った分だけかかります。

使うAI

どれが正確かはまだ分かりません。食事の写真の画面にある「3つのAIで比べる」で、同じ写真の結果・秒数・費用を並べて見られます。

キーはこのiPhoneの中だけに保存します（「データを書き出す」のファイルにも入りません）。送るのは食事の写真とメモだけで、体重などの記録は送りません。
